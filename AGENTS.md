# Instruções do projeto

## Validação

Este projeto não utiliza GitHub Actions, por decisão do mantenedor.
Não adicione nem reative workflows em `.github/workflows/` sem uma nova
solicitação explícita do mantenedor.

Mantenha os testes disponíveis para execução local. Quando uma alteração
precisar de validação, execute as verificações adequadas localmente e informe
o resultado, sem criar automações no GitHub.

Os comandos e dependências de testes estão no README.md e em docs/VPN.md.
